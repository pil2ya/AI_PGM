## 1. 객체 지향 프로그래밍 (OOP) 기초

### 🔹 클래스 (Class) & 생성자 (Constructor)
* **클래스**: 객체(인스턴스)를 만들기 위한 **설계도**나 틀입니다.
* **생성자 (__init__)**: 객체가 생성될 때 **자동으로 호출**되는 특수 메서드로, 주로 객체의 초기 속성(변수)을 설정합니다.
* **self**: 생성된 객체 '자기 자신'을 가리키는 파이썬의 약속입니다.

> 💡 추가 상식 (인스턴스 변수 vs 클래스 변수)
> * 인스턴스 변수: self.name처럼 각 객체마다 독립적으로 가지는 값.
> * 클래스 변수: 클래스 바로 아래 선언하며, 모든 객체가 공유하는 변수. (예: 개수_카운트 = 0)

[코드 예시]
class Character:
    # 클래스 변수 (모든 캐릭터가 공유)
    game_name = "파이썬 RPG"

    # 생성자 (인스턴스 변수 초기화)
    def __init__(self, nickname, hp):
        self.nickname = nickname  # 인스턴스 변수
        self.hp = hp              # 인스턴스 변수

---

### 🔹 특수 연산자 (매직 메서드 / 던더 메서드)
* 파이썬 내부적으로 미리 정의된, 더블 언더스코어(__)로 시작하고 끝나는 메서드입니다.
* 단순히 객체끼리 더하거나(+), 객체를 출력할 때의 행동을 커스텀할 수 있습니다.
* __str__(self): print(객체)를 했을 때 보여줄 문자열을 정의합니다. (가장 많이 씀!)
* __add__(self, other): 객체 간에 + 연산을 할 때 실행될 로직을 정의합니다.

## 2. 객체 지향의 확장: 상속과 오버라이딩

### 🔹 상속 (Inheritance)
* 기존 클래스(부모)의 기능과 속성을 그대로 물려받아 새로운 클래스(자식)를 만드는 것입니다.
* 장점: 코드의 재사용성이 극대화되고 유지보수가 쉬워집니다.

### 🔹 오버라이딩 (Overriding - 재정의)
* 부모에게 물려받은 메서드를 자식 클래스에서 입맛에 맞게 바꾸는 것입니다.
* 주의: 덮어쓰는 것(Overriding)이지, 이름은 같고 매개변수만 바꾸는 오버로딩(Overloading)과는 다릅니다! (파이썬은 순수 오버로딩을 지원하지 않음)

> 💡 추가 상식 (super())
> * 부모 클래스의 기능을 완전히 바꾸는 게 아니라, "부모 기능 + 알파"를 하고 싶을 때 자식 메서드 안에서 super().부모메서드()를 호출합니다.

[코드 예시]
class Monster: # 부모
    def attack(self):
        print("기본 공격!")

class BossMonster(Monster): # 상속
    def attack(self): # 오버라이딩
        super().attack() # 부모의 기본 공격 실행
        print("💥 광역 필살기 추가!!") # 자식만의 독자적 기능

## 3. 인터페이스: GUI와 CLI

프로그램이 사용자와 소통하는 방식(인터페이스)의 두 가지 양대 산맥입니다.

* CLI (Command Line Interface)
  - 개념: 글자(텍스트) 명령어로 소통하는 환경
  - 특징: 개발자 친화적, 가볍고 빠름, 자동화 유리
  - 예시: 터미널, CMD, Git Bash
  - 파이썬 라이브러리: sys.argv, argparse

* GUI (Graphical User Interface)
  - 개념: 그래픽(아이콘, 창, 버튼)으로 소통하는 환경
  - 특징: 일반 사용자 친화적, 직관적, 무거움
  - 예시: 윈도우 창, 웹 브라우저, 포토샵
  - 파이썬 라이브러리: tkinter (기본), PyQt, PySide

## 4. 데이터 사이언스의 시작: 넘파이(Numpy)와 벡터화 연산

### 🔹 넘파이 (Numpy)
* 파이썬의 기본 리스트보다 훨씬 빠르고 메모리를 적게 쓰는 대용량 수치 계산용 라이브러리입니다.
* 핵심 자료구조는 ndarray (N-차원 배열)입니다. (파이썬 리스트와 달리 한 가지 데이터 타입만 담을 수 있음)

### 🔹 벡터화 연산 (Vectorized Operation)
* 반복문(for문)을 쓰지 않고도 배열의 모든 요소에 한 번에 연산을 적용하는 기술입니다.
* 내부적으로 C언어로 구현되어 있어 파이썬 for문보다 압도적으로 빠릅니다.

[코드 예시]
import numpy as np

# 파이썬 리스트라면 for문을 돌려야 하지만,
# 넘파이는 그냥 배열에 2를 곱하면 알아서 모든 요소가 2배가 됨 (벡터화 연산)
arr = np.array([1, 2, 3])
print(arr * 2) # 결과: [2, 4, 6]

## 5. 개발 환경의 격리: 파이썬 가상환경 (Virtual Environment)

### 🔹 왜 사용할까? (필수 이유)
* 프로젝트마다 필요한 라이브러리의 버전 충돌을 방지하기 위해 컴퓨터 안에 독립적인 방을 만드는 것입니다.
* A 프로젝트는 Tensorflow 1.x, B 프로젝트는 Tensorflow 2.x가 필요할 때 가상환경이 없다면 컴퓨터 환경이 꼬이게 됩니다.

### 🔹 핵심 명령어 (기본 venv 모듈 기준)

1. 가상환경 생성: python -m venv 가상환경이름
2. 가상환경 활성화 (Activate):
   - Windows (CMD): call 가상환경이름\Scripts\activate
   - Windows (PowerShell): .\가상환경이름\Scripts\Activate.ps1
   - Mac / Linux: source 가상환경이름/bin/activate
3. 가상환경 비활성화 (Exit): deactivate

> 💡 추가 상식 (패키지 내보내기/가져오기)
> * 내가 가상환경에 설치한 라이브러리 목록 저장: pip freeze > requirements.txt
> * 다른 컴퓨터(혹은 팀원)가 협업할 때 한 번에 설치: pip install -r requirements.txt
